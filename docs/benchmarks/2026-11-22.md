## Notes on this run

- **Correctness is read from the last of the 10 runs.** Every engine gives
  the same score on every run except Chromium's `requestAnimationFrame`:
  headless Chromium fires rAF only when it produces a frame, and with
  `--print-to-pdf` it fired in 10 of 20 separate runs. So its `modern-js`
  is 18 or 19 of 19.
- **wkhtmltopdf and the frameworks 0.** QtWebKit cannot parse ES2015+
  (classes, arrow functions, modules), so those scripts never run.
- **sghtmltopdf and WeasyPrint have no JavaScript.** Their `turkish` scores
  are the non-JavaScript checks; WeasyPrint passes the language-sensitive
  `text-transform` ones, sghtmltopdf does not.
- **Fonts.** The `ligature-text` line is now drawn in Comfortaa through
  `@font-face`. Before, it used `font-family: serif`, which on this machine
  is a font without ligatures, so the check passed without testing
  anything (on the Fedora machine bdhtml2pdf failed it: `office` extracted
  as `ofce`). All five engines load Comfortaa; bdhtml2pdf, sghtmltopdf,
  Chromium and WeasyPrint draw the ff, ffi and ffl ligatures and map each
  to all of its letters, wkhtmltopdf draws no ligatures. wkhtmltopdf 5/8:
  no WOFF2, and it finds no CJK or Arabic font here.
- **Install size.** WeasyPrint is its pipx virtualenv; Python and Pango from
  the system are not counted. Chromium is `/usr/lib/chromium`, without the
  shared system libraries it links to.
- **Page size.** Chromium prints Letter, the others A4, so page counts differ.
- **Security times are single runs,** not medians. The verdicts are the
  same as in the first run of the day and, for the four engines measured
  then, as on 2026-11-19.
- **sghtmltopdf's and WeasyPrint's ✅ on the JavaScript cases** only reflect
  that they have no JavaScript.
- **WeasyPrint security:** it does not read `file://` URLs from iframes,
  objects or redirects, but applies CSS from outside the input directory
  (also through a symlink), and its HTML/CSS and SVG images reach
  127.0.0.1. 20 000 nested elements stop it with an error after 27 s (20 s
  in the first run of the day).
